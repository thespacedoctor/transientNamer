# transientNamer

Python package and command-line tool that queries the IAU Transient Name Server (TNS).

## Agent skills

### Issue tracker

Issues live in Linear, team `thespacedoctor`, project `transientNamer`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five triage states are Linear workflow statuses (`Triage`, `needs-info`, `ready-for-agent`, `ready-for-dave`, `wontfix`), and `bug` and `enhancement` are labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
